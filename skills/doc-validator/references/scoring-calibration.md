# 分數校準

補充 `SKILL.md` 的 Confidence Score。信心指數是質化判斷，這裡只提供錨點與上限，讓不同輪次、不同審查者的分數可以比較；不是扣分表。

## 1. 內容保真軸錨點（僅 Migration）

可用性軸沿用 `SKILL.md` 的錨點表。保真軸與「出現『其他』即不合格」一致：有未補回的「其他」，保真軸不得高於 89%。

| 分數 | 意義 |
|---|---|
| 95-100% | 逐段對照無「其他」；搬運型內容全量腳本比對；新增皆有來源或已登記授權 |
| 90-94% | 沒有未補回的「其他」；僅有已補回，或不涉及規則與行為的瑕疵（如措辭、排版） |
| 70-89% | 有未補回的「其他」（內容遺失），或語意被改寫 |
| <70% | 大量遺失，或規則被改變 |

## 2. 驗證覆蓋率是信心上限

信心不能高於驗證實際涵蓋的範圍：

- 全量用工具比對的內容，才能支持 ≥95%。
- 只靠肉眼抽讀的區塊，上限約 93%。
- **未做讀者走查**：可用性軸的判定是「未能判定（驗證缺口）」，不是不合格。分數宣稱上限 89%，只作為天花板（不能宣稱更高）；整體判定也是「未能判定」。要宣稱合格，必須補做走查。使用者明確同意免走查時，由使用者決定如何處理並在報告註明。
- 驗證缺口是流程限制，不計入文件缺陷的扣分歸因。

## 3. 報告寫法

- 分數附 ± 範圍，反映驗證的不確定性（工具全量比對範圍小，抽讀範圍大）。
- B 類預期分數要寫估算依據，同類問題跨輪分值一致；最小單位 0.5 分。預期分數只用來排修正優先序，不是機械換算（「一筆『其他』扣 N 分」這類換算會與質化判斷互相拉扯）。
- 分數剛好壓在門檻時，在理由中說明偏向哪一邊的取捨與依據。
