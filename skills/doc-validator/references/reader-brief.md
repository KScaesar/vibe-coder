# 讀者說明

適用條件：交給讀者走查的讀者（人或 subagent）。審查者把本檔與任務說明一起交給讀者；讀者只讀本檔、任務說明與被審查的文件。

你的角色：第一次接觸這套文件的讀者。只靠被審查的文件完成任務說明中的每一題，如實回報你怎麼找、找到什麼、哪裡卡住。

## 1. 可讀範圍

- 只讀任務說明指定的目錄，其餘一律不讀。
- 不執行文件中的指令或程式碼，只閱讀。
- 任務說明若指定了替代的搜尋或列檔方式，照指定方式進行。

## 2. 回報

回報第一行自述是否讀過可讀範圍以外的檔案：「違規：無」，或列出讀過的檔案。

每一題回報以下內容。

**路徑表**：

| 步 | 檔案#章節 | 到達方式 | 接觸程度 |
|---|---|---|---|

接觸程度：

| 接觸程度 | 定義 |
|---|---|
| opened | 讀取整個檔案或大段內容 |
| peeked | 只看到搜尋匹配行或片段 |
| listed | 只看到檔名或目錄列表 |

**答案**，並標註信心層級：

| 信心層級 | 定義 |
|---|---|
| 明載（Explicit） | 答案在文件中有直接寫出 |
| 推得（Inferred） | 文件沒有直接寫，但由相鄰文字可以合理推論出答案 |
| 猜測（Guessed） | 文件找不到依據，憑記憶或常識作答 |

**卡點**，每個卡點標類別：

| 卡點類別 | 意思 |
|---|---|
| 找不到入口 | 不知道該從哪個檔案開始 |
| 找到但讀不懂 | 內容在，但前置知識或用詞無從理解 |
| 缺資訊 | 文件沒有寫，需要猜 |
| 需跨檔拼湊 | 答案散在多處，必須同時開多個檔 |

**疑似缺口**：把信心層級為「推得」或「猜測」的答案另列成清單，寫明是哪一題、你依據哪段文字推論或為何只能猜。
