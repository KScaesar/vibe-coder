# 審查協定（多輪或多審查者）

適用於實作者與審查者分工、或需要多輪修正的審查，是 `SKILL.md` 的 Validation Process 的補充。

## 1. 獨立判斷與主張重驗

- **順序**：先讀來源、再讀新文件、最後才讀實作者回報，避免被自述結論帶著走；對照做法見 [migration-acceptance.md](migration-acceptance.md) 第 1 節。
- **主張必須重驗**：實作者回報中的事實性主張（如「一致」「來源原有」「沒有…」），審查者要用工具或對照原文自己重算，不可直接採信，也不引用實作者的輸出。實作者有誘因把問題歸給來源，因為 A 類不扣分。
- **A 類需附獨立證據**：判為 A 類必須附審查者自己取得的證據（來源位置、腳本輸出）；沒有就暫列 B 類。
- **省略清單**：實作者的清單只是起點，審查者另自行整理，兩份取聯集。

## 2. 編號與重審

- 違規清單每項有編號：一般問題 R1、R2…，來源缺陷 A1、A2…；重審沿用同一組編號。
- 重審模板：

| 編號 | 項目 | 判定 | 證據 |
|---|---|---|---|
| R1 | … | 已解決 / 部分 / 未解決 / 撤回 | … |

  加上回歸抽查（隨機重走已通過的區塊）與重新評分的信心指數。與前輪重複且沒有變動的章節可省略。
- **撤回**：先前判斷被推翻（如重算後發現不成立）時，標「撤回」，說明錯在哪，並重算分數。
- **回復**：本輪建議與先前輪次相反時，寫明原因與新依據，列為 B 類「回復」，避免實作者來回修改。
- 只重走受影響的讀者任務，其餘抽查。

## 3. A 類與重審

- 凍結的是項目與判定，不是分數。
- 使用者授權處理後，視為已解決並加回分數；使用者維持現狀則轉為 C 類。
- 重審時重新確認該項來源仍如此，避免來源已被更正卻仍凍結。

## 4. 來源缺陷與來源內說法有出入

- 問題若來源本身就有（矛盾、歧義、覆蓋不全），逐項對照來源確認後歸 A 類，不算重構退步，也不由審查者擅自補答案。
- 來源內說法有出入時，依可信度擇一：可驗證的測試 > 實作程式碼 > 敘述性文字，記錄依據；判斷不出來就兩邊保留並交給使用者。
- 讀者走查產生的「疑似缺口」（見 [reader-walkthrough.md](reader-walkthrough.md) 第 6 節）也走這個流程：對照來源後，來源沒有的歸 A 類，來源有但新文件遺失的歸 B 類。

## 5. 範圍授權登記

Migration 中使用者核准的新增內容（超出「只搬移不新增」的部分）逐項登記範圍與來源，未列入者一律視為新增違規。

## 6. B 類標註執行者

每個 B 類項目標明由誰修：實作者可修，或審查者端動作（如補讀者走查）。審查者端的缺口不派給實作者，也不當成文件缺陷扣分。預期分數的寫法見 [scoring-calibration.md](scoring-calibration.md)。

## 7. 對歸類的異議

實作者可對審查者的歸類提出異議，尤其是 C 類與「reference 含理由」這類判斷（避免同一句話移走又移回）：

- 異議要附理由，例如「拿掉這句，讀者是否可能誤用」的判斷。
- 審查者在下一輪回應：同意就改歸類並標「撤回」；不同意就寫明依據。
- 同一項異議只處理一次；回應後以審查者的判定為準，不再來回。

## 8. 派遣 agent 的實務

派審查者、實作者或讀者給其他 agent 時：完成以預期輸出檔出現為準，不採信工具回報的「done」；給確認過的絕對路徑，避免不同 agent 寫到不同位置。

## 9. 結案條件

事先約定輪數上限與合格門檻。達標，或剩餘扣分全為 A、C 類時即可結案。結案不改變判定：未達門檻仍如實標為不合格，並註明剩餘扣分待使用者決策；因未做讀者走查而無法判定者，標為「未能判定」（見 [scoring-calibration.md](scoring-calibration.md)）。

## 10. 實作者交接（Migration 開工前）

返工多半來自「事後才知道標準」，開工前把本節交給實作者：

- 確認目標讀者、約束（如不新增規則、ID 不變、是否保留來源）與哪些內容已授權可刪，並請使用者確認。
- 先讀完來源再動手，盤點每一段的類型與去向，盤點放暫存區不進專案。
- 讀來源時列出「來源缺陷」（矛盾、歧義、覆蓋不全）並先問使用者，這是 A 類預告。
- 邊做邊記：省略清單（欄位見 [migration-acceptance.md](migration-acceptance.md) 第 1 節）與新增內容登記（檔案、段落、來源、第 2 節的分級；超出授權的先問），沒搬的當場登記。
- 交回前自跑 [mechanical-checks.md](mechanical-checks.md) 的檢查並補洞。
- 回報內容：機械檢查結果（含差集）、最終目錄結構與偏離之處、省略清單、待判斷清單（說法有出入處、去重時刪了哪份、不確定的分類）、新增內容登記、發現但未處理的問題。每個事實性主張附證據，會被審查者重驗（第 1 節）。
